Common questions

Before you write

When does OmniKin launch?

Early access opens region by region through 2026, foundations first. The upcoming modules page always shows the current order.

What does it cost?

Free to start, with a household subscription for the fuller set of modules. No advertising tier, because there will not be any advertising.

Do children get their own logins?

Yes. Every member has a distinct credential. Children's accounts are set up by a parent or guardian and start with protective defaults.

What if I have no email address?

Phone number with a 6-digit code is a full sign-in path, not a fallback. It matters for reach, so we treat it as a first-class route.
